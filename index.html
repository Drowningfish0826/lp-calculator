使用說明

    
一般線性規劃

    
    
      
  1. 選擇問題類型（最大化或最小化），輸入決策變數個數，系統會自動產生輸入欄位。
    2. 
      
  2. 輸入目標函數係數與各限制式（係數、符號 ≤ / = / ≥、右端常數 RHS）。可按「＋ 新增限制式」增加限制式。
    3. 
      
  3. 可取消個別變數的非負限制，也可將變數指定為整數（xᵢ ∈ Z）或 0-1（xᵢ ∈ {0,1}）。
    4. 
      
  4. 頁面會即時顯示完整數學模型。按下「求解」後顯示最佳解、最佳目標函數值、管理意涵、限制式分析與敏感度分析。
    5. 
      
  5. 決策變數為兩個時，會自動繪製限制式、可行區域、最佳解與等利潤線（等成本線）。
    6. 
    

    
輸入欄位可使用小數或分數（例如 0.5、1/3）。

    
管理科學範本

    
運輸問題：輸入供給地與需求地數量 → 輸入成本矩陣、供應量、需求量 → 建立模型 → 求解 → 檢視最佳運輸方案與結果分析。

       指派問題：輸入人員與工作數量及成本（或效益）矩陣 → 建立模型 → 求解 → 檢視最佳指派。

    
名詞解釋

    
    
      
  • Binding Constraint（緊束限制）：在最佳解時等號成立的限制式，代表該資源已用盡（或需求剛好滿足）。
    • 
      
  • Slack / Surplus（鬆弛量）：≤ 限制式尚未用完的資源量；≥ 限制式超出下限的量。
    • 
      
  • Shadow Price（影子價格）：右端常數增加 1 單位時，最佳目標函數值的變化量；僅在「允許範圍」內有效。
    • 
      
  • Reduced Cost（減少成本）：強迫一個未被採用的變數增加 1 單位時，目標函數值的變化量。
    • 
    

    
技術說明

    
本系統以 HTML / CSS / JavaScript 開發，求解引擎為 HiGHS（以 WebAssembly 編譯，已內嵌於 lib/ 資料夾）。所有計算皆在瀏覽器本機完成，不需要網路連線；直接以瀏覽器開啟 index.html 即可使用。
